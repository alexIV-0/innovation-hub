## Что это за продукт

Один Next.js-проект, внутри которого живут четыре разные системы:

1. **Публичный сайт** — витрина видеоработ: главная с бесконечной лентой и
   фильтрами по тегам, страница работы, «О нас», контакты, форма предложений.
2. **Кабинет клиента** (`/account`) — файловый менеджер проектов в облаке:
   дерево файлов, загрузка, переименование, корзина, расшаривание, чат с
   командой, параметры обработки, развёрнутое описание проекта, статистика,
   раздел «Инструменты».
3. **Админка** (`/admin`) — управление контентом витрины, людьми, посещениями,
   статистикой, парком машин и **Конвейером** (наблюдение за обработкой всех
   проектов сайта).
4. **Машинный API** — сайт как оркестратор для парка обрабатывающих машин
   (десктопное приложение `fs.manager.tauri`): синхронизация файлов, общие
   словари, очередь задач.

Домен продакшена — `ffworks.pro`. Раздача медиа — `cdn.ffworks.pro`.
